AI 컴포저 DeepSeek

한국어 요청을 검증된 41축과 콘텐츠로 구성한 뒤 기존 결정론적 프롬프트 생성기에 적용
보안·연결 안내: 키는 이 탭의 입력 메모리에만 둡니다. 브라우저 개발자 도구나 확장 프로그램에서는 키를 볼 수 있습니다. DeepSeek는 브라우저 직접 호출과 file:// 지원을 공식 보장하지 않습니다. CORS 오류가 나면 문서의 로컬 HTTP 서버를 시도해 보세요. 항상 해결되는 것은 아닙니다. 계속 차단되면 프록시/백엔드가 필요합니다.
API 키와 요청을 입력하면 현재 수동 설정을 검증된 결과로 한 번에 교체합니다.

#### [00:00 - 00:03] "이 결혼! 절대 허락 못 한다!"
* **화자 추정:** 50대~60대 중년 남성 (아버지 역할 추정)
* **음높이 / 음색:** 중저음 / 목이 쉰 듯 굵고 거친 허스키 톤
* **에너지 / 감정:** 매우 높음 / 극도로 화가 난 ‘버럭’ 호통
* **말투 / 속도:** 막장 드라마풍의 과장되고 위엄 있는 말투 / 중간 속도
* **억양:** 표준어 (드라마틱한 억양 강조)
* **효과:** 공간감이 느껴지는 약간의 웅장한 리버브(잔향)

#### [00:06 - 00:08] "두 분 궁합은 천생연분입니다."
* **화자 추정:** 20대~30대 여성 (앱 음성 안내 / 시스템 목소리)
* **음높이 / 음색:** 중간~높음 / 차분하고 맑은 톤
* **에너지 / 감정:** 보통 / 격식 있고 친절하며 단정한 감정
* **말투 / 속도:** 정중한 안내 말투 / 또박또박한 중간 속도
* **억양:** 표준어
* **효과:** 스마트폰 스피커 필터 (하이패스/밴드패스 필터로 인한 전화/앱 음성 효과)

#### [00:09 - 00:11] "사주천궁이 오케이면 나도 오케이!"
* **화자 추정:** 50대~60대 중년 남성 (00:00과 동일 인물)
* **음높이 / 음색:** 중고음 / 시원하고 쾌활한 목소리
* **에너지 / 감정:** 매우 높음 / 180도 전환된 태도로 매우 기뻐하고 호탕함
* **말투 / 속도:** 코믹하게 크게 지르는 말투 / 약간 빠름
* **억양:** 표준어

#### [00:11 - 00:14] "나도 해봤어! 사주천궁 보고 결혼했다!"
* **화자 추정:** 50대~60대 중년 남성 (동일 인물)
* **음높이 / 음색:** 중고음 / 힘있고 울림이 큰 목소리
* **에너지 / 감정:** 매우 높음 / 당당하고 자신감에 찬 외침
* **말투 / 속도:** 자랑하듯 강조하는 말투 / 빠름
* **억양:** 표준어

#### [00:15 - 00:17] "궁합이 궁금하면 사주천궁!"
* **화자 추정:** 20대~30대 여성 (전문 성우 / 광고 내레이터)
* **음높이 / 음색:** 높은 음 / 밝고 경쾌한 톤
* **에너지 / 감정:** 높음 / 상큼하고 활기찬 브랜드 홍보 감정
* **말투 / 속도:** 선명한 광고 멘트 말투 / 보통 속도
* **억양:** 표준어
* **효과:** 깨끗한 스튜디오 스피커용 마스터링 음성
